All modules follow the same step format: {"name", "mod", "method", "params"}. Data flows between steps via @step_name.key references.

How to call any module method via the Flask API

1. Create a workflow with the module step:

curl -X POST \
  -H "X-Api-Key: <your-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "flow_name": "my_http_test",
    "procedures": {
      "procedures": [
        {
          "name": "fetch",
          "mod": "common.Http",
          "method": "get",
          "params": {"url": "https://httpbin.org/json"}
        }
      ]
    }
  }' \
  http://127.0.0.1:5001/flow

2. Run the workflow and get results:

curl -X POST \
  -H "X-Api-Key: <your-key>" \
  http://127.0.0.1:5001/flow/my_http_test/run

# Then get the result using the run_id from above:
curl -H "X-Api-Key: <your-key>" \
  http://127.0.0.1:5001/run/<run_id>
